# Compiler web-site



Он создан для компиляции HTML/CSS/JS кода онлайн с любого устройства с возможностью кастомизации.



## Особенности проекта:

* Мобильная оптимизация: Задний фон останавливается на мобильных устройствах для экономии ресурсов.

* Кроссбраузерность: Проект отлично оптимизирован и стабильно работает в любом браузере.

* Установка сайтов: Написанный веб-сайт можно установить (скачать), в чём и есть главная прелесть проекта.

* Адаптивная верстка: Вместо фиксированных пикселей (`px`) использовались единицы `vh` и `vw`, которые автоматически подстраиваются под любой размер экрана.



## Запуск проекта

Для запуска откройте файл `index.html` в вашем браузере.
